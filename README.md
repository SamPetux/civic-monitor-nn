# Civic Monitor НН

Платформа мониторинга и визуализации влияния инфоповодов на гражданскую
активность и настроения в социальных медиа Нижнего Новгорода.

## Текущий блок: визуализация

Сейчас в проекте реализован UI-слой: интерактивная карта районов
с цветовой индикацией и боковой панелью. Источник данных —
`modules/mock_data.py` (детерминированные моки).

Дальнейшие блоки (по плану):
1. **Сбор данных** — `vk_api`-парсер локальных и общегородских групп.
2. **Геокодинг** — извлечение адресов из текста и привязка к району.
3. **Sentiment** — RuBERT (`rubert-base-cased-sentiment-rusentiment`).
4. **Topic modeling** — BERTopic + SBERT.
5. **Burst detection** — z-score / change-point по временным рядам.
6. **БД** — SQLite/Postgres + SQLAlchemy.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate         # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Подготовка данных (один раз)

```bash
python prepare_data.py
```

Скачает границы 8 районов из OpenStreetMap → `data/districts.geojson`.
Если интернет недоступен / `osmnx` не поставился — упадёт в fallback
с упрощёнными границами, чтобы UI всё равно стартовал.

## Запуск

```bash
streamlit run app.py
```

Откроется по адресу http://localhost:8501.

## Структура

```
nn_civic_monitor/
├── app.py                 # главный Streamlit-app
├── prepare_data.py        # разовый загрузчик границ районов
├── requirements.txt
├── modules/
│   ├── districts.py       # 8 районов + 5 локальных VK-групп на каждый
│   ├── visualization.py   # Folium-карта с градиентом
│   └── mock_data.py       # моковые данные (заменим реальной выборкой)
└── data/
    └── districts.geojson  # генерируется prepare_data.py
```

## Что сейчас работает в UI

- Карта НН, 8 районов, градиент зелёный → красный по уровню негатива.
- Tooltip при наведении (район, постов, % негатива).
- Клик по району → боковая панель с метриками, диаграммой тональности,
  графиком динамики за 30 дней, списком 5 мониторимых VK-групп.
- Вкладка «Топ авторов»: таблица самых активных за 30 дней,
  средний эмоциональный окрас, флаг подозрения на бота, чек-бокс
  «Исключить из карты» (синхронно перерисовывает блок комментариев).
